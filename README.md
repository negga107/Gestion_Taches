
# Gestion des tâches

## Description
Cette application Python permet de gérer les tâches quotidiennes
à travers une interface en ligne de commande.

## Fonctionnalités
- Ajouter une nouvelle tâche.
- Afficher la liste des tâches.
- Rechercher une tâche par mot-clé.
- Quitter le programme.

## Technologies utilisées
- Python
- Visual Studio Code
- Git
- GitHub

## Étapes réalisées
1. Création du projet.
2. Développement de l'application Python.
3. Test des fonctionnalités.
4. Gestion du projet avec Git et GitHub.

## Exécution du programme
1. Ouvrir le dossier du projet dans VS Code.
2. Ouvrir le fichier main.py.
3. Cliquer sur le bouton "Run Python File".
